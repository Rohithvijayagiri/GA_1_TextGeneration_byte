An API is an interface that lets one software system request a service or data from another system. A restaurant is a useful analogy: you choose an item from the menu, give your order to the waiter, and receive the prepared result. The kitchen is hidden behind the interface. Technically, an API defines endpoints, request formats, authentication rules, and response formats so clients can communicate with a service in a predictable way. For example, a client might send a JSON request to a weather API and receive current temperature and forecast data as a JSON response.
